# 正式实验执行清单

本轮只做验证和图表，不撰写报告。保留两轮预试验的估计：1 天约 24 次，7 天约 30–31 次；正式结果不得回填到这些估计。

- 使用现有 100 万行原始文件，不重新生成或修改数据。
- 验证窗口起点为 6 月 3、7、11、15、19、23 日，未参与预试验估计；查询长度分别为 1 天、7 天。
- N 固定为 1、10、20、22、23、24、25、26、28、29、30、31、32、33、34、36、40、50、100，每条件重复 5 次。
- 每轮先固定 100 条查询的序列；两种布局、两种窗口共用起点序列；每个 N 实际执行该序列前 N 条，整批开始到完成使用真实计时。
- 各 N 和窗口的执行次序在轮内随机化，布局先后交替。预热不计入批次；结果核对在计时结束后执行。
- 在 E 盘重新测量 3 次全量读取、排序和写出。主图使用 R 的中位数，另保留全部 3 次 R 的敏感性结果。总成本是实测 R + 实测整批查询时间，不将单次均值乘以 N 冒充实测，也不宣称两部分是一个连续计时区间。
- 预试验在 C 盘，本轮在 E 盘；位置改变记录为环境变化，不能直接把变化归因于物理硬盘速度。
- 全量逐字段一致性、每次查询的 count/sum/avg 都必须通过。
- 每点绘制 5 轮中位数、最小至最大范围。范围是描述性波动，不是置信区间。所有慢轮次保留。
- 回本位置报告为相邻测量次数之间的区间，不通过插值假装测到了每个整数。主要口径为配对净节省中位数转正且在后续已测 N 上保持为正；另外报告 5/5 轮全部转正的位置。
- config_frozen.json 在计时前保存所有参数、序列、调度和预试验引用哈希。events.jsonl 逐组追加原始计时。

执行：使用安装好依赖的 Python 运行 formal_experiment.py --run-id formal_20261117_01，随后运行 plot_formal.py --run-id formal_20261117_01。已存在的实验目录不会覆盖。
